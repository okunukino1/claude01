# 駐車許可申請 区域図（parking_permit）

警察署への駐車許可申請に添付する「区域図（見取図）」を、ブラウザで表示・印刷するためのページです。
用紙はすべて A4縦 1枚ずつで、次の構成になっています。

- 1枚目：**全体図**（申請区域すべて）
- 2枚目以降：**町別の拡大図**（日本橋小舟町店なら 本石町／室町／本町／小舟町 の4枚）

町別の拡大図は縮尺が約 1:2,600〜1:5,200 と全体図（約1:6,200）より大きく、道路や街区が読み取りやすくなります。

## 使い方

1. `index.html` をブラウザで開く（公開後は `https://rys-services.com/delivery_map_mapbox/parking_permit/`）。
2. 上部のツールバーで営業所を選ぶ。
   - 日本橋小舟町店 … 既定（`?store=kobunacho`）
   - 浜町店 … `?store=hamacho`
3. 営業所★の位置を合わせる。
   - 「🔍 住所から位置」… 所在地欄の住所を検索して★を移動（サイト上 `rys-services.com` に置いたページでのみ利用可。既存の `api/geocode_address.php` を使うため）。
   - 「📍 店舗位置を設定」… 押してから地図をクリック、またはマーカーをドラッグして手動で合わせる。番地までの微調整はこちらが確実。
4. 「🅿 駐車予定地点を追加」を押してから地図をクリックすると、番号付きのピンが立ち、下の表に「場所・備考」を書き込める。
   - ピンは右クリックで削除、ドラッグで移動。
5. 表題・営業所・所在地・対象区域・用途・作成日の各欄は、クリックしてそのまま書き換えられる（営業所名は全ページで同期）。
6. 町別ページの地図はドラッグ／ズームして、そのページに写る範囲を調整できる（「🔄 表示範囲リセット」で既定に戻る）。
7. ツールバーの **印刷する用紙** で出す枚数を選ぶ。
   - 全体図＋町別（5枚）… 既定
   - 全体図のみ（1枚）
   - 町別のみ（4枚）
8. 「🖨 印刷 / PDF保存」で印刷ダイアログへ。用紙 A4・向き 縦・**背景のグラフィック（背景色と画像）を ON** にすると、表の罫線と凡例の色が正しく出ます。

駐車予定地点は全ページに番号付きで表示され、下段の一覧表には**そのページの町に入る地点だけ**が載ります（番号は全体の通し番号のまま）。

営業所位置・駐車予定地点・記入した備考は、そのブラウザの localStorage に営業所ごとに保存されます
（`parking-permit-store-v1:<営業所キー>` / `parking-permit-spots-v1:<営業所キー>`）。

## 対象区域を変える／営業所を増やす

`index.html` 内の `STORE_PROFILES` を編集します。

```js
kobunacho: {
  name: '日本橋小舟町店',
  address: '東京都中央区日本橋小舟町',
  store: { lat: 35.686672, lng: 139.778364 },   // ★の初期位置
  groups: [
    { label: '日本橋本石町 1〜4丁目', color: '#d2413a', names: chome('日本橋本石町', [1,2,3,4]) },
    ...
  ]
}
```

`groups` の1件が町別ページ1枚に対応します（`key` はページの識別用）。
`names` に書ける町名は `../data/chuo_nihonbashi_boundaries.geojson` の `properties.name`（中央区日本橋地区の全町丁目）です。
このページは同じ境界データを HTML 内に埋め込んで持っているため、単体のファイルとしても動きます。
境界データを差し替えたときは、`index.html` 内の `const BOUNDARIES = {...}` も更新してください。

## 注意

- **★の初期位置は町の代表点（仮）** です。申請前に「🔍 住所から位置」または手動で実際の営業所位置へ合わせてください。
  日本橋小舟町店の所在地は `〒103-0024 東京都中央区日本橋小舟町4-6` を既定で記載しています。
- 背景地図は国土地理院「地理院タイル」、区域界は e-Stat 小地域境界データ（出典はページ下部に明記済み）。
- 地図と Leaflet はオンラインで読み込むため、印刷時はネット接続が必要です。
