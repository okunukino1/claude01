# 駐車許可申請 区域図（parking_permit）

警察署への駐車許可申請に添付する「区域図（見取図）」を、ブラウザで表示・印刷するためのページです。
A4縦 1枚に収まるようにレイアウトしてあります。

## 使い方

1. `index.html` をブラウザで開く（公開後は `https://rys-services.com/delivery_map_mapbox/parking_permit/`）。
2. 上部のツールバーで営業所を選ぶ。
   - 日本橋小舟町店 … 既定（`?store=kobunacho`）
   - 浜町店 … `?store=hamacho`
3. 「📍 店舗位置を設定」を押してから地図をクリック（またはマーカーをドラッグ）すると、営業所★の位置を合わせられる。
4. 「🅿 駐車予定地点を追加」を押してから地図をクリックすると、番号付きのピンが立ち、下の表に「場所・備考」を書き込める。
   - ピンは右クリックで削除、ドラッグで移動。
5. 表題・営業所・所在地・対象区域・用途・作成日の各欄は、クリックしてそのまま書き換えられる。
6. 「🖨 印刷 / PDF保存」で印刷ダイアログへ。用紙 A4・向き 縦・**背景のグラフィック（背景色と画像）を ON** にすると、表の罫線と凡例の色が正しく出ます。

営業所位置・駐車予定地点・記入した備考は、そのブラウザの localStorage に営業所ごとに保存されます
（`parking-permit-store-v1:<営業所キー>` / `parking-permit-spots-v1:<営業所キー>`）。

## 対象区域を変える／営業所を増やす

`index.html` 内の `STORE_PROFILES` を編集します。

```js
kobunacho: {
  name: '日本橋小舟町店',
  address: '東京都中央区日本橋小舟町',
  store: { lat: 35.686672, lng: 139.778364 },   // ★の初期位置
  groups: [
    { label: '日本橋本石町 1〜4丁目', color: '#d2413a', names: chome('日本橋本石町', [1,2,3,4]) },
    ...
  ]
}
```

`names` に書ける町名は `../data/chuo_nihonbashi_boundaries.geojson` の `properties.name`（中央区日本橋地区の全町丁目）です。
このページは同じ境界データを HTML 内に埋め込んで持っているため、単体のファイルとしても動きます。
境界データを差し替えたときは、`index.html` 内の `const BOUNDARIES = {...}` も更新してください。

## 注意

- **★の初期位置は町の代表点（仮）** です。申請前に実際の営業所位置へ合わせてください。
- 背景地図は国土地理院「地理院タイル」、区域界は e-Stat 小地域境界データ（出典はページ下部に明記済み）。
- 地図と Leaflet はオンラインで読み込むため、印刷時はネット接続が必要です。
